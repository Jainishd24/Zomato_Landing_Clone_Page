# 🍽️ Zomato Landing Page Clone

A responsive and visually appealing landing page clone of Zomato, built using HTML and CSS. This project replicates the core visual design of Zomato's homepage to showcase front-end development skills, focusing on layout structure, styling, and responsiveness.

## 🔍 Features

- ✅ Clean and modern UI inspired by the official Zomato website
- 📱 Fully responsive design – compatible with mobile, tablet, and desktop devices
- 🔍 Search bar for restaurants, cuisines, and locations (static)
- 🌐 Location selector interface
- 🖼️ Hero section with background image and logo
- 🔽 Dropdown styled navigation
- 📷 Restaurant cards with images and descriptions (static content)
- 📦 Organized and modular CSS codebase

## 💡 Project Objective

The goal of this project is to replicate a real-world landing page using only HTML and CSS. This enhances proficiency in layout design, responsive techniques (media queries), and visual presentation, preparing for full-stack development by understanding the frontend structure first.

## 🛠️ Tech Stack

- **HTML5** – For semantic page structure
- **CSS3** – For styling and layout
- **Google Fonts** – For modern typography
- **Font Awesome** – For icons and UI elements
